# Veloris Lab

Сайт инженерного бюро. Раньше жил маршрутом `/lab` внутри монорепозитория Swiftin,
теперь стоит отдельно.

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

## Маршруты

| Путь | Язык | Файл |
|---|---|---|
| `/` | английский | `src/app/(en)/page.tsx` |
| `/ru` | русский | `src/app/(ru)/ru/page.tsx` |

Две корневые раскладки в группах маршрутов, а не одна общая: только корневая
раскладка может отрисовать `<html>`, а каждому языку нужен честный атрибут
`lang`. Иначе русская страница объявляла бы себя английской.

## Где что лежит

```
src/
  app/               только маршруты, по 6 строк каждый
  site/
    Lab.tsx          вся разметка страницы
    labData.ts       ВЕСЬ ТЕКСТ, на двух языках
    labPricing.ts    прайс калькулятора
    lab.css          дизайн-система, обычный CSS без Tailwind
    Calculator.tsx   пятишаговый расчёт
    HeroCopy.tsx     заголовок по словам
    HeroTexture.tsx  фактура героя, рисуется на canvas
    Pipeline.tsx     схема автоматизации
    CopyEmail.tsx    копирование почты
    routing.ts       адреса и hreflang
    meta.ts          метаданные, JSON-LD, контракт направления
```

Правки текста — только в `labData.ts`. Правки цен — только в `labPricing.ts`.

## ⛔ Перед публикацией

**Прайс в калькуляторе черновой.** В `labPricing.ts` стоит `PRICING_IS_DRAFT = true`,
и внутри калькулятора висит янтарная плашка. Замените числа на настоящие и
поставьте флаг в `false`. Нужны: 6 базовых цен, 3 коэффициента готовности,
9 доплат за галочки, стоимость поддержки, вилки сроков.

**Задайте домен.** Скопируйте `.env.example` в `.env.local` и укажите
`NEXT_PUBLIC_SITE_URL`. Без него канонические адреса, hreflang и JSON-LD уедут
на `http://localhost:3000`.

## Дизайн-система, коротко

Серый холст `#ececed`, белые карточки на общих волосяных линиях, одна тёмная
поверхность `#0f1614`, повторённая трижды: полоса героя, блок цены, финальный
призыв. Акцент — зелёный `#0e7c66` на светлом и `#35debc` на тёмном, только на
действиях. Углы 4px, ничего круглого. Inter для текста, JetBrains Mono для
подписей, тегов и цифр.

Полный контракт направления лежит HTML-комментарием в `src/site/meta.ts` и
попадает в собранную разметку.
